# Dealerships Review Portal - Full Stack Capstone Project

A comprehensive web application for "Best Cars Dealership", a national car retailer in the United States. This platform enables users to browse dealership locations, filter dealerships by state, read verified customer reviews, analyze sentiment with natural language processing, and post new reviews for purchased vehicles.

## Tech Stack
- **Frontend**: React.js, HTML5, CSS3, Bootstrap
- **Backend**: Django 4.x, Python 3.12
- **Microservices**:
  - Express.js & MongoDB (Dealerships & Reviews API)
  - Flask & NLTK (Sentiment Analysis API)
- **Database**: SQLite (Car Models & Makes), MongoDB (Dealerships & Reviews)
- **DevOps & Cloud**: Docker, Kubernetes, IBM Cloud Code Engine, GitHub Actions CI/CD
